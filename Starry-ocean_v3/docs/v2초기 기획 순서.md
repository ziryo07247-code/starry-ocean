# 🚀 AI-Powered Smart Memo Project - Portfolio Roadmap

## 1. Project Overview & Core Value

- **프로젝트 명:** AI 기반 스마트 메모 & 시맨틱 검색 플랫폼 (가칭)
- **기획 의도:** 단순 CRUD를 넘어, 대규모 텍스트 데이터의 **AI 임베딩 처리 성능 분석**과 **Node.js / Spring 멀티 백엔드 구조 비교**, **클라우드 인프라(AWS/NCP) 멀티 배포**를 경험하여 아키텍처 설계 역량을 증명하기 위한 프로젝트.
- **핵심 차별점 (Why this project?):**
  - 의미 기반 유사도 검색 및 연관 메모 추천 (AI 임베딩 도입 목적 명확화)
  - 대량 데이터(100~500건) 임베딩 처리 시 병목 구간 분석 및 최적화
  - 동일 비즈니스 로직의 Node.js(Express) vs Spring Boot 성능 및 구조 비교

---

## 2. Phase-by-Phase Implementation Roadmap

### [Phase 0] Planning & Architecture (기획 및 설계)

- **목표:** 프로젝트 전체 뼈대 설계 및 문서화 완료
- **주요 산출물:**
  - **시스템 아키텍처 다이어그램:** 프론트엔드, API 서버, DB, 외부 AI API 간의 통신 구조도
  - **ERD (Entity Relationship Diagram):** `User`, `Memo` (`title`, `content`, `vector_embedding`), `Tag` 테이블 설계
  - **기획서(PRD):** 서비스 핵심 유저 플로우 및 AI 임베딩이 기여하는 사용자 가치 정의

### [Phase 1] MVP Core Development (Node.js 기반 코어 구축)

- **목표:** 기본 기능 구현 및 AI 파이프라인 연동
- **기술 스택:** React, Node.js (Express), MySQL, OpenAI API (또는 오픈소스 임베딩 모델)
- **세부 작업:**
  - [ ] **DB 구축:** MySQL 연동 및 메모 스키마(Title 컬럼 포함) 생성
  - [ ] **Backend CRUD:** 메모 생성, 조회, 수정, 삭제 API 구현
  - [ ] **Frontend UI:** React 기반 메모 작성(팝업 모달), 목록 관리 UI 구현
  - [ ] **AI 임베딩 연동:** 메모 저장 시 텍스트를 벡터로 변환하여 DB에 함께 저장하는 파이프라인 구축

### [Phase 2] Performance Benchmarking & Optimization (성능 측정)

- **목표:** 대량 데이터 처리 성능 분석 및 최적화 경험 확보 (면접 핵심 어필 포인트)
- **세부 작업:**
  - [ ] **더미 데이터 구축:** 100건 ~ 500건의 테스트 메모 데이터 생성 스크립트 작성
  - [ ] **임베딩 처리 시간 측정:** 동기(Sync) 처리 방식 vs 비동기/배치(Asynchronous/Batch) 처리 방식에 따른 소요 시간 비교 벤치마크 진행
  - [ ] **병목 분석 및 개선:** I/O 블로킹 현상 분석 및 개선 과정 보고서 작성 (Grafana/Log 혹은 console 타임스탬프 활용)

### [Phase 3] Backend Migration & Infra Scale-up (확장 및 비교)

- **목표:** 백엔드 아키텍처 다변화 및 클라우드 배포 경험
- **세부 작업:**
  - [ ] **Spring Boot 마이그레이션:** 기존 Node.js로 구현한 백엔드를 Spring Boot로 재구현 (또는 MSA/아키텍처 확장성 비교 포인트 정리)
  - [ ] **Cloud Deployment:**
    - AWS (EC2, RDS) 및 NCP (Naver Cloud Platform) 에 각각 배포 실습
    - 클라우드 환경별 비용, 네트워크 지연, 제공 서비스(DB, 인프라 관리) 비교 트레이드오프 분석 정리
  - [ ] **프론트엔드 배포:** Vercel 또는 S3 + CloudFront를 통한 React 클라이언트 배포
